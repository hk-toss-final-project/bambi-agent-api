# agent/ — LangGraph 에이전트

Bambi Agent API의 에이전트 로직을 담는 디렉터리입니다.
LLM 호출, 그래프 정의, 도구 연동 등 "에이전트가 생각하고 행동하는" 코드는 모두 여기에 둡니다.
FastAPI 관련 코드(라우터, 요청/응답 스키마)는 여기에 두지 않고 `app/`에 둡니다.

## 디렉터리 구조

```
agent/
  graph.py        # LangGraph 그래프 정의 (노드 연결, 엣지, 컴파일)
  state.py        # 그래프 상태(State) 정의
  <기능>/api.py        # 기능 영역의 공개 facade
  <기능>/features/*.py # 역할과 변경 이유별 실제 기능 구현 모듈
  nodes/          # 그래프 노드 (노드 하나당 파일 하나)
  tools/          # 에이전트가 사용하는 도구 (Tavily 검색 등)
  prompts/        # 프롬프트 템플릿 (코드와 분리해서 관리)
```

> 아직 없는 디렉터리는 해당 기능을 처음 구현할 때 만듭니다. 위 구조는 배치 기준입니다.

## 작성 규칙

- 노드 함수는 상태를 입력받아 상태(부분 업데이트)를 반환하는 순수한 형태로 작성하고, 노드 하나당 책임 하나를 유지합니다.
- 프롬프트는 코드에 하드코딩하지 않고 `prompts/`에 분리합니다. 프롬프트를 수정하면 해당 기능의 벤치마크(`bench/`)를 다시 실행해야 합니다.
- 모델명, temperature 등 LLM 파라미터는 상수나 설정으로 한곳에 모아 관리합니다.
- API 키는 환경변수로만 주입합니다. (루트 `AGENTS.md` 6번 규칙)
- 기능 구현은 `features/` 아래 역할별 모듈에 두고, `api.py`에서는 공개 함수만 다시 노출합니다.
- 모든 함수에 한국어 docstring, 모든 파일 상단에 한국어 파일 주석을 작성합니다.

## 테스트와 벤치마크

- 노드/도구의 로직 검증은 `tests/`에서 LLM을 mock으로 대체해 작성합니다.
- 실제 LLM을 호출하는 품질 평가는 `bench/<기능이름>/`에 작성합니다.
