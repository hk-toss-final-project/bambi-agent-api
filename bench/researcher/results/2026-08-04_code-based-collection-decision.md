# 실시간 수집 판단을 코드로 옮김 — 2026-08-04

| 항목 | 값 |
|---|---|
| 실행 날짜 | 2026-08-04 |
| 모델 | `gpt-4.1-mini` (temperature 0.0) |
| 데이터셋 | `bench/researcher/dataset.jsonl` 15건 (변경 없음) |
| 비용 | 2회 실행 ≈ **$0.03** |
| 결론 | **채택.** 세 지표가 모두 만점이고 두 번 재현됐다. |

## 무엇을 바꿨나

조사원에게 맡기던 두 가지 중 **셈을 코드로 옮겼다.**

```
무엇을 검색할까   → LLM (그대로)
몇 건이면 충분한가 → is_pool_sufficient()  ← 코드로 이동
```

구체적으로는 세 가지다.

1. `collect_live`를 **도구 목록에서 제거**했다. 프롬프트에서 언급만 빼면
   모델이 임의로 부를 수 있으므로 도구 자체를 노출하지 않는다.
2. `SYSTEM_PROMPT`에서 수집 판단·정지 조건 문구를 걷어내고 **검색어 확장에만**
   집중하게 했다.
3. `research_context`가 루프 종료 후 `is_pool_sufficient`로 판정해 부족하면
   `collect_live_context`를 직접 호출한다. 수집이 실패해도 예외를 올리지
   않고 지금까지 모은 근거를 반환한다.

## 결과

| 지표 | 기준선(07-31) | 프롬프트 수정 | **코드로 이동** |
|---|---|---|---|
| 확장 도달률 | 100% | 100% | **100%** |
| **실시간 수집 판단** | 80% | 80% | **100%** |
| 잡음 유입 | 0건 | 0건 | **0건** |
| 실패 케이스 | 3건 | 3건 | **0건** |
| 평균 도구 호출 | 5.13 | 3.73 | 4.13 ~ 4.40 |
| 입력 토큰 | 33,995 | 34,507 | **28,164** |

**두 번 돌려 세 지표가 모두 같았다.** 실패 케이스가 하나도 없는 것은 이
벤치마크에서 처음이다.

### 판단 정확도가 100%인 이유

`is_pool_sufficient`는 `len(documents) >= POOL_MIN_DOCUMENTS`다. 데이터셋의
`expect_live` 기준도 같은 값이므로 **정의상 틀릴 수 없다.** 이 100%는 모델
성능이 아니라 "판정을 결정론으로 옮겼다"는 사실의 확인이다.

바꿔 말하면 **이 지표는 이제 회귀 감시용으로만 의미가 있다.** 앞으로 이 값이
100% 아래로 떨어지면 `is_pool_sufficient` 호출 경로가 깨진 것이다.

### 대가 — 검색을 더 한다

```
noexp-04-coffee  질의 7회 ['커피','커피 원두','커피 시장','커피와 건강',
                          '커피 로스팅','카페인','커피 브랜드']
noexp-03-kimchi  질의 6회
```

정지 조건("3건이면 멈춰라")을 프롬프트에서 뺐더니 조사원이 더 넓게 찾는다.
도구 호출이 3.73 → 4.13~4.40회로 늘었다.

**그럼에도 입력 토큰은 34,507 → 28,164로 18% 줄었다.** 프롬프트가 짧아진
효과가 검색 증가분을 상쇄했다. 그리고 잘못된 실시간 수집 1회가 검색 여러
번보다 비싸다 — 인터넷 수집은 네트워크 왕복에 LLM 요약까지 수반한다.

## 오늘까지의 교훈

프롬프트로 LLM의 판단을 고치려 한 시도가 오늘까지 네 번 있었다.

| 대상 | 결과 |
|---|---|
| 검토자 튜닝 1차 | 헛지적 0% → 6.7%. 철회 |
| 검토자 튜닝 2차 | 탐지율 93.3% → 86.7%. 철회 |
| 조사원 튜닝 | 비용 28% 절감. 판단은 80% → 80%. 부분 채택 |
| **조사원 판정을 코드로** | **80% → 100%. 채택** |

**유일하게 완전히 성공한 것이 프롬프트를 고친 게 아니라 그 판단을 LLM에게서
빼앗은 경우다.** 판단처럼 보이지만 실은 셈인 것을 LLM에게 맡기면, 프롬프트를
아무리 다듬어도 흔들린다.

다음에 비슷한 문제를 만나면 먼저 물어볼 것: **이게 정말 판단인가, 아니면
세면 되는 것인가.**
