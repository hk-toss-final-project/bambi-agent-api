# 근거 검색 잡음 측정 — 임베딩 유사도 필터를 붙이지 않기로 한 이유

작성일: 2026-08-05

## 요약

리포트 근거 검색에서 **관련 문서와 잡음의 점수 간격이 0.01 미만**이라 어떤
임계값으로도 가를 수 없다는 것이 반복 확인됐다. 키워드 비서(`agent/selection`)가
쓰는 임베딩 유사도 필터를 이 경로에도 붙이면 해결될지 실측했다.

**결론: 지금 형태로는 붙이지 않는다.** 얻는 것보다 잃는 것이 크다. 방향 자체가
틀린 것은 아니므로 측정값을 남긴다.

## 문제 — 검색 점수가 관련성을 가르지 못한다

점수는 `GREATEST(trigram similarity, ts_rank)`다. 실측에서 두 번 같은 모양이
나왔다.

```
창고 검색     "블록체인"        → 방탄소년단 기사 0.087
              관련 문서          0.098          간격 0.011

개인 Wiki     "고대 이집트 미라" → RBW(걸그룹 소속사) 0.103
              관련 문서          0.112          간격 0.009
```

원인은 **수집 본문이 기사 본문이 아니라 페이지 통짜**라는 데 있다. 2.6만~4.5만
자에 사이드바·관련기사 목록·메뉴가 섞여 들어가므로, 흔한 단어는 어느 문서에나
한 번씩 등장한다. 위 방탄소년단 기사에도 "블록체인"이 실제로 들어 있다.

## 측정 방법

같은 문서 집합에 대해 검색 점수와 임베딩 코사인 유사도를 나란히 계산했다.

- 모델: `text-embedding-3-small` (`agent/selection`과 동일)
- 입력: 제목 + 본문 앞 900자
- 컷오프: `max(SIMILARITY_FLOOR 0.25, 최고유사도 × SIMILARITY_RATIO 0.75)`
  — 키워드 비서의 공식을 그대로 적용
- 대상: 오늘 잡음을 실제로 목격한 검색어 5개, 로컬 DB(mock-clipping-user)
- 비용: 1원 미만

## 결과

### 잘 되는 경우 — `코스피`

```
                              검색점수  유사도
코스피, 사이드카 이어 서킷브레이커  0.098   0.551  통과
데이식스 영케이, 멜론 1-15위        0.098   0.203  탈락
환율 월평균 39.1원 끌어내린 수급    0.097   0.137  탈락
```

검색 점수 간격 0.000 → 유사도 간격 0.35. 검색 점수가 못 하던 구분을 해낸다.

### 진짜 근거를 버리는 경우 — `반도체`

```
0.535  통과  반도체 산업 투자
0.440  통과  반도체 원톱 넘어 선박·뷰티까지…수출, 1조달러
0.288  탈락  TSMC
0.270  탈락  삼성전자
0.245  탈락  SK하이닉스
```

컷오프가 `max(0.25, 0.535 × 0.75) = 0.402`이 되어 관련 문서 3건이 탈락한다.
**같은 날 배포에서 가장 잘 나온 리포트의 근거가 SK하이닉스·삼성전자였다.**
이 필터를 붙였으면 둘 다 사라진다.

### 전부 잡음일 때 통과시키는 경우 — `커피 원두 로스팅`

```
컷오프 0.250
0.290  통과  딥파인, 한화시스템과 물류 AI 에이전트 개발
0.260  통과  API 키 발급 방법
0.253  통과  [#클라우드 월드] 딥파인 '산업용 AI 에이전트'
```

`블록체인`에서도 방탄소년단 기사(0.301)가 통과하고 보안·개발 기사(0.233~0.252)가
탈락했다. 방향이 거꾸로다.

## 왜 그대로 옮기면 안 되는가

키워드 비서의 공식은 **"오늘 수집한 뉴스 중에서 고르기"** 용도로 만들어졌다.
후보가 전부 그 키워드로 검색해 온 것들이라 **1등이 관련 있다는 가정**이 성립한다.

리포트 근거 검색은 다르다.

| | 키워드 비서 | 리포트 근거 검색 |
|---|---|---|
| 후보 구성 | 그 키워드로 수집한 것만 | 잡음이 섞임 |
| 1등의 성격 | 관련 있다고 가정 가능 | 잡음일 수 있음 |
| 상대 비율(0.75) | 스케일 차이를 흡수 | 1등이 튀면 진짜를 버림 |
| 절대 하한(0.25) | 쓰레기 차단 | 잡음이 0.30까지 올라와 무력 |

관련 문서 최저(0.245)와 잡음 최고(0.301)가 **역전**되어 있어, 절대 하한 하나로도
가를 수 없다.

## 판단

붙이지 않는다.

```
얻는 것   코스피 같은 케이스에서 잡음 제거
잃는 것   반도체 같은 케이스에서 진짜 근거 3건 손실
```

현재 증상은 "쓸모없는 근거가 섞임"이고, 붙였을 때의 증상은 "좋은 근거가 사라짐"
이다. 후자가 더 나쁘다.

## 다시 시도한다면

임베딩 자체에는 신호가 있다(간격 0.009 → 0.35). 공식이 문제지 방향이 틀린 것은
아니다. 제대로 하려면 세 가지가 필요하다.

1. **컷오프 공식 재설계** — 상대 비율은 이 경로의 후보 구성에 맞지 않는다.
   하드 컷 대신 유사도 기준 재정렬 + 상위 N건 방식도 후보다.
2. **임베딩 입력 정리** — 지금은 페이지 통짜 본문이 그대로 들어간다.
   `clean_article_body`를 저장 시점에 적용하면 검색 점수도 함께 나아진다.
3. **데이터셋과 벤치마크** — 위 케이스들을 케이스로 만들어 회귀를 잡아야 한다.

근본 해결은 1이 아니라 **2**일 가능성이 높다. 잡음이 통과하는 원인이 애초에
"본문이 기사 본문이 아니라서"이기 때문이다.
